# Car Shop Management System

A desktop application built for managing car shop operations, inventory, and billing. Developed using Java Swing and MySQL database.

## 🛠️ Tech Stack & Tools

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Database:** MySQL
- **Database Design:** MySQL Workbench (`.mwb`)
- **Reporting & Invoicing:** JasperReports (`.jrxml` / `.jasper`)
- **Build Tool:** Apache Ant (`build.xml`)

## ✨ Key Features

- **Inventory Management:** Track available vehicles and spare parts.
- **Supplier & Customer Details:** Manage suppliers and customer records.
- **Automated Billing:** Generate printable invoices using JasperReports.
- **Database Connectivity:** Real-time data search and update using MySQL JDBC connector.

## 📁 Repository Structure

- `src/` - Contains Java source code (`.java`) and Swing GUI form definitions (`.form`).
- `Database/` - Database design files and ER diagrams (`CarShop.mwb`).
- `jars/` - External Java libraries and dependencies required for JasperReports, MySQL connector, etc.
